# Documentação

Esta pasta reúne os artefactos académicos e técnicos do projeto Economia com História - Angola.
O objetivo é centralizar os documentos de análise, modelação e desenho da solução para facilitar consulta, revisão da equipa e avaliação da disciplina.

```text

└── prototipo/    -> Materiais de prototipagem
```
