# Requisitos não Funcionais

| Código | Descrição |
|--------|----------|
| RNF01 | A aplicação deve apresentar uma interface simples, intuitiva e de fácil navegação. |
| RNF02 | O sistema deve permitir acesso às funcionalidades principais em até 3 cliques. |
| RNF03 | A interface deve ser responsiva para dispositivos móveis e web. |
| RNF04 | O sistema deve ser compatível com Android e navegadores modernos. |
| RNF05 | O tempo de resposta deve ser inferior a 2 segundos. |
| RNF06 | O sistema deve suportar múltiplos utilizadores simultaneamente. |
| RNF07 | A aplicação deve permitir funcionamento parcial offline. |
| RNF08 | O sistema deve estar disponível 24/7. |
| RNF09 | Os dados dos utilizadores devem ser protegidos. |
| RNF10 | O sistema deve implementar autenticação segura. |
| RNF11 | O sistema deve garantir integridade dos dados. |
| RNF12 | O sistema deve permitir expansão modular. |
| RNF13 | O sistema deve ser de fácil manutenção. |
| RNF14 | A tipografia deve ser legível. |
| RNF15 | O design deve garantir bom contraste de cores. |
| RNF16 | O sistema deve manter consistência visual. |
| RNF17 | A linguagem deve ser clara e acessível. |
| RNF18 | O sistema deve permitir atualização de conteúdos. |
| RNF19 | O sistema deve evitar perda de dados. |
| RNF20 | O sistema deve refletir a realidade angolana. |

---

## Considerações Finais

Os requisitos não funcionais são essenciais para garantir a qualidade do sistema, assegurando uma experiência de utilização eficiente, segura e acessível, alinhada ao contexto educacional angolano.
