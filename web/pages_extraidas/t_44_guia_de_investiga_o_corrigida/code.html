Normas de Publicação & Metodologia

rule Protocolos de Submissão
expand_more

Investigadores externos podem submeter 'Microtextos' para revisão pelos pares. O processo segue três etapas rigorosas:

  • Verificação de fontes primárias angolanas.
  • Validação de métricas económicas por especialistas.
  • Adequação ao tom editorial 'Modern Editorial' da plataforma.
analytics Tratamento de Dados Estatísticos
expand_more

Nossos dados são harmonizados utilizando modelos de deflação ponderada para garantir a comparabilidade entre o período colonial e a era pós-independência.
